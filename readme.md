### 翻訳方針
この私家訳は以下の点を重視している。

- 既存の5E製品と併用する時の違和感を極力減らすこと
- 日本語としてしっかり読めること(AI・機械による翻訳は有用だが、青桃書房が目指す基準にはまだ達していない、日本語に訳すことと、しっかり読める日本語に訳すことの間には大きな差があるものだ)
- 自由！(原文と同じCC-BY4.0ライセンスに従う限り、一部だろうが大部分だろうが全体だろうが勝手にやっちまえい！エンジョイ！)

主に1つ目と2つ目の理由により、原文にはない語を多少補ったり捻ったりして訳している箇所もある。原文に忠実になり過ぎると、訳文の読者をないがしろにすることになることもある。兎に角、青桃書房が原文と訳文の両方に誠実でいようと頑張っているということは頭の隅とかに入れといてほしい。
